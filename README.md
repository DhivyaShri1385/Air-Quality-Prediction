## Air Quality Prediction

This project aims to analyze and forecast air quality using machine learning and deep learning models. It includes an interactive dashboard built with **Streamlit** for easy visualization and user interaction.

## 🚀 Features

- Predicts AQI (Air Quality Index) using:
  - Linear Regression
  - LSTM (Long Short-Term Memory)
- Interactive Dashboard using Streamlit
- Forecasts air quality for the next 7 days
- Clear visualizations and model evaluation metrics

## 🧠 Technologies Used

- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib, Seaborn
- Streamlit
